# Dynox Tech Computers — Frontend Website

A responsive, online-first website built with HTML, CSS and vanilla JavaScript.

## Open in Visual Studio Code
1. Extract `dynox-tech-computers-frontend.zip`.
2. Open Visual Studio Code.
3. Select **File → Open Folder** and choose this folder.
4. Open `index.html` in a browser. For live reload, install the VS Code **Live Server** extension and choose **Open with Live Server**.

## Main files
- `index.html` — page structure and content sections.
- `css/styles.css` — colours, layout, responsive styling and visual design.
- `js/config.js` — business contact settings. Change WhatsApp number/email here.
- `js/services.js` — service catalogue, descriptions and prices.
- `js/main.js` — search, category filters and WhatsApp booking behaviour.

## Current website features
- Responsive layout for phones, tablets and computers.
- Service catalogue with search and category filters.
- Listed service fees and service descriptions.
- Individual Book Now buttons that open WhatsApp with the service name and listed fee pre-filled.
- General WhatsApp and email contact links.

## Important notes before publishing
- Prices are the Dynox assistance fees in KES. Government, statutory, portal and third-party charges are separate unless specifically stated.
- The catalogue intentionally presents Dynox as an online-first service. Virtual training is advertised; computer support may be arranged on-site after booking. Walk-in cyber café, printing and photocopying are not advertised.
- This is the **frontend-only first version**. It does not yet include a backend, database, admin dashboard, customer accounts, or a live AI assistant. Those can be added in a later stage.
- The contact information is centralised in `js/config.js`.
- External Google Fonts require an internet connection; the site remains readable with fallback fonts if they do not load.

## Before launch
Review service scopes and prices, confirm the WhatsApp number and email, add any final brand logo/assets, and test every booking link on a phone and desktop.
